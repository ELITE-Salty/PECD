# PECD - Smart Plant Monitoring System

Course project for *Programming of Energy-Constrained Devices* (FRI, 2026/27),
Manuel Gonçalves and Nik Kopi.

| Folder | Content |
| --- | --- |
| **[`FINAL_Smart_Plant_NM/`](FINAL_Smart_Plant_NM/README.md)** | **Final submission**: ESP32 firmware, Raspberry Pi code, configuration, Monsoon measurements, analysis scripts, results and the report |
| [`Labs/`](Labs/) | Lab exercises and early prototypes, kept for reference only (not part of the final system) |

## Labs/
